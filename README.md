# 💰 Expense Tracker

A simple **Python-based Expense Tracker** that allows users to add expenses, view all recorded expenses, and calculate their total spending.

## 📌 About

This is a beginner-friendly Python project created to practice fundamental programming concepts such as:

* Lists
* Dictionaries
* Loops
* Conditional statements
* User input
* Functions and basic data handling

## ✨ Features

* ➕ Add a new expense
* 📋 View all recorded expenses
* 💵 Calculate total expenses
* 🚪 Exit the application
* 🔢 Automatically number recorded expenses

## 🛠️ Technologies Used

* **Python 3**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/JAFFSzZz/Expense_Tracker.git
```

### 2. Open the project folder

```bash
cd Expense_Tracker
```

### 3. Run the program

```bash
python tracker.py
```

## 🖥️ How It Works

When you run the program, you will see a menu:

```text
*---Menu---*
1. Add expense
2. View all expense
3. View total expense
4. Exit!
```

Choose an option by entering the corresponding number.

### Add Expense

The program asks for:

* Date
* Item purchased
* Amount spent

### View All Expenses

Displays all expenses that have been added during the current session.

### View Total Expense

Calculates and displays the total amount of all recorded expenses.
